# 🌐 Ans Shahid — Personal Developer Portfolio

A fully responsive, modern personal portfolio website built from scratch with **HTML5**, **CSS3**, and **JavaScript**.

## ✨ Features

- **Glassmorphism Navbar** — Fixed navigation with a frosted glass effect and smooth scroll
- **Animated Hero Section** — Typing animation, morphing profile frame, and gradient accents
- **About Section** — Education, experience, and achievement cards with hover effects
- **Skills Section** — Categorized skill progress bars with animated fill on scroll
- **Projects Showcase** — Interactive project cards with tech tags and live/demo links
- **AI Chat Assistant** — Built-in RAG-powered AI chatbot to answer questions about me
- **Contact Section** — Email CTA with social media links
- **Dark Theme** — Modern dark aesthetic with purple accent gradients
- **Mobile-First Responsive** — Fully responsive across all screen sizes
- **Smooth Animations** — Scroll-triggered fade-in animations throughout

## 🛠 Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Semantic structure |
| CSS3 | Styling, animations, glassmorphism |
| JavaScript | Interactivity, typing effect, AI chat |
| Google Fonts | Space Grotesk & Syne typography |
| GitHub Pages | Hosting & deployment |

## 🏗 Setup & Deployment

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ans108/ansshahid_portfolio.git
   ```

2. **Open locally:**
   ```bash
   cd ansshahid_portfolio
   open index.html
   ```

3. **Deploy:** Automatically deployed via GitHub Pages using the included workflow.
